# Mini Program visual production guide

## App icon

1. Extract three semantic anchors from the product's real purpose.
2. Check existing brand ownership and third-party trademark risk.
3. Present three original directions with motif, palette, silhouette, and small-size behavior.
4. Obtain a direction choice before replacing approved brand files.
5. Export from a large master and then optimize the live-dashboard size.

Use a strong square composition, clear silhouette, and limited tiny detail. Do not use the WeChat logo, Mini Program glyph, or another product's recognizable icon as the primary mark unless the user has explicit rights.

## Screenshots

Build a real three-to-five-screen story:

1. home and value
2. core action
3. result
4. optional secondary capability
5. optional completion, order, export, or account state

Use one device size, realistic synthetic content, and consistent status-bar treatment. Avoid personal WeChat data, production orders, phone numbers, openids, addresses, and private chats.

Keep unedited captures for review evidence. If promotional framing or captions are produced, export them separately and ensure they do not imply nonexistent controls or results.

## Share and campaign assets

Share cards, launch images, and Mini Program code posters are optional marketing assets rather than universal release requirements.

- Record the current target placement and required ratio before designing.
- Keep the app icon, product name, and one benefit visible.
- Preserve a clear quiet zone around the Mini Program code.
- Never stretch, recolor, obscure, or fabricate the code.
- Use the code generated for the intended environment and page path.

## Rights and accessibility

- Confirm font, illustration, photo, mockup, and icon licenses.
- Use adequate contrast and readable text.
- Check low-end-device rendering and dark mode when supported.
- Do not add fake rankings, awards, review scores, or official endorsements.
