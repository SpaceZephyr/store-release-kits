# 微信小程序发布检查清单

## 账号与资质

- [ ] 主体、管理员和开发者权限正确
- [ ] 小程序认证状态满足当前功能
- [ ] 服务类目与实际功能一致
- [ ] 类目所需资质已准备
- [ ] 已确认适用的备案状态

## 代码与构建

- [ ] `project.config.json` 和 `miniprogramRoot` 正确
- [ ] `app.json`、页面、分包、插件和 tabBar 资源有效
- [ ] 已运行生产构建、lint 和测试
- [ ] 已查看 DevTools 或 CI 的主包、分包和总包大小
- [ ] 已在真机预览准确的上传目录
- [ ] 关闭“不校验合法域名”后网络仍正常
- [ ] 未提交 AppSecret、access_token、上传私钥或测试密码

## 网络与后端

- [ ] request/upload/download/WebSocket 域名已配置
- [ ] 使用 HTTPS/WSS 和有效证书
- [ ] 域名和适用备案状态满足平台要求
- [ ] AppSecret 和 access_token 只在服务端
- [ ] 第三方 SDK、插件、云函数和数据接收方已盘点

## 隐私

- [ ] 后台《小程序用户隐私保护指引》与代码一致
- [ ] 每项隐私接口或组件都有对应声明
- [ ] 授权前不会调用受限接口
- [ ] 拒绝授权、同意授权和指引变化流程已测试
- [ ] 隐私政策、保留期限、删除和注销渠道准确
- [ ] 用户可打开隐私保护指引

## 素材与审核

- [ ] 小程序头像符合当前后台尺寸和格式
- [ ] 已准备 3–5 张真实页面截图
- [ ] `asset-spec.json` 记录当前后台要求
- [ ] 简介、服务类目、标签和功能说明准确
- [ ] 页面路径与截图一一对应
- [ ] 审核人员测试路径可复现
- [ ] 测试账号通过安全渠道提供
- [ ] 无真实个人信息或生产数据出现在素材中

## 发布

- [ ] 版本号、项目备注和更新说明已准备
- [ ] 已设置并验证体验版
- [ ] 已完成回归和真机测试
- [ ] 上传、提交审核、全量发布或分阶段发布分别获得授权
- [ ] 已准备回滚和问题响应方案
