# 动效风格库

每种风格由五部分组成：**皮肤**（配色、字体、圆角、投影）、**入场动作**（文字 / 截图 / 卡片）、
**一组轮换的转场**、**背景层**、**可选装饰**（重点词划线 `mark`、背景描边大字 `ghost`）。
镜头运动、旁白对位、放大镜是所有风格共用的，见 SKILL.md「动效怎么组织」。品牌色（`accent` / `accent2`）会覆盖风格默认色，所以换产品不用改风格代码。

挑风格先看两件事：**产品调性**（严肃还是好玩、高端还是大众），**投放渠道**（官网首屏、发布会、短视频信息流）。

## apple-keynote · 发布会极简

- **长什么样**：纯黑底，白色大字带银色渐变，重点词用品牌色渐变。截图从下方慢慢浮起，底部有呼吸的品牌色柔光。
- **动作**：标题模糊淡入（blurIn），副标题上浮淡入；logo 慢速模糊聚焦；截图从下方带透视立起来（swing3d）；转场在模糊推进（blurPush）和穿越推进（zoomThrough）之间轮换。没有背景大字。节奏偏慢（pace 1.15）。
- **配乐**：ambient，84 bpm，铺底和弦 + 稀疏琶音，没有鼓。
- **适合**：硬件发布、旗舰功能、高端品牌、需要「质感」的场合。
- **不适合**：信息密度高的介绍、要求轻松好玩的消费产品。
- **参考**：Apple 发布会、Apple 官网产品页的开场动画。

## saas-glow · 科技光晕

- **长什么样**：深蓝黑底，三团品牌色光斑缓慢漂移，网格线向下流动，玻璃质感卡片，重点词用双色渐变。
- **动作**：标题逐字从 -90° 翻起来（rise3d）；截图带透视立起来（swing3d），卡片从景深里翻过来（flip3d）；转场轮换 zoomThrough / whip / blurPush。
- **配乐**：tech，104 bpm，小调和弦 + 琶音 + 轻鼓。
- **适合**：SaaS、AI 产品、开发者工具、B 端平台、技术发布。
- **参考**：Linear、Vercel、Stripe、Raycast 的发布视频。

## kinetic · 快节奏大字（Kinetic Typography）

- **长什么样**：超大超粗的字占满屏幕，每一场底色在 品牌色 / 黑 / 副色 / 白 之间轮换，标签变成描边大字横向滚动。
- **动作**：标题逐字从 2.6 倍砸下来带旋转（charSlam）；kicker 硬切滑入；转场轮换闪白 / 甩镜 / 旋转 / 竖条（0.3s）。节奏最快（pace 0.8）。
- **配乐**：beat，124 bpm，四拍底鼓 + 拍手 + 贝斯。
- **适合**：抖音 / 视频号 / B 站信息流投放、活动预热、年轻品牌、促销。
- **注意**：文案要短，一句不超过 8 个字，不然大字会折成好几行。竖版尤其要手动用 `\n` 断句。

## flat-mg · 扁平 MG 动画

- **长什么样**：浅色底，四周漂浮着圆、圆环、三角、加号、波浪线，粗描边卡片和截图框，kicker 是胶囊标签。
- **动作**：逐字弹跳带轻微旋转（charPop），重点词底下划一道色带；截图带透视立起来，卡片弹性放大入场（popBounce）；转场轮换品牌色色块 / 圆形展开 / 竖条 / 甩镜。
- **配乐**：bouncy，116 bpm，大调跳跃琶音 + 轻鼓。
- **适合**：消费 App、社区、教育、儿童、生活服务、二次元 / 年轻用户产品。
- **参考**：支付宝、B 站、Duolingo 的功能介绍 MG。

## editorial · 杂志编辑

- **长什么样**：米色纸张噪点底，宋体大标题，强调色下划线，背景有斜体描边大字缓慢横移。（v1 的外框、刊头和页码已去掉：固定页框和页码是「翻页 PPT」的标志。）
- **动作**：标题按行从遮罩下推上来（maskUp）；截图从左往右擦出（wipe）；logo 字距收拢（letterSpace）；转场轮换上推 / 模糊推进 / 竖条。节奏偏慢。
- **配乐**：ambient。
- **适合**：内容平台、媒体、文化品牌、生活方式、咨询和专业服务、年度报告。
- **注意**：宋体在 PingFang 之外，标题里的英文和数字会偏细，必要时用 `fontFile` 换字体。

## neo-brutal · 新粗野主义

- **长什么样**：奶黄底 + 点阵，所有元素 5px 黑描边 + 硬投影，高饱和品牌色块，重点词用色块打底。
- **动作**：所有东西都是阶梯式（step easing）滑入，像逐帧动画一样「卡」进来；重点词背后的色块从左往右刷出来；转场轮换四色带 / 竖条 / 甩镜。
- **配乐**：beat。
- **适合**：独立开发者产品、创意工具、潮牌、Figma 社区风格的产品、想显得「有态度」的品牌。

## cyber-glitch · 赛博故障

- **长什么样**：黑底，透视网格地面向前滚动，扫描线，暗角，霓虹色 logo 发光，卡片切角。
- **动作**：标题乱码解码 + RGB 分离（glitch）；kicker 和副标题打字机效果；截图带故障撕裂入场；转场轮换故障切 / 甩镜 / 穿越推进。标签默认弹幕模式。
- **配乐**：synth，100 bpm，锯齿感琶音 + 底鼓。
- **适合**：游戏、电竞、Web3、潮流科技、动漫、硬核极客产品。
- **注意**：故障效果别用在需要传达「稳定可靠」的产品上（金融、医疗、企业服务）。

## bento · 便当格

- **长什么样**：浅灰底，白色大圆角卡片网格（第一张跨两行），干净克制，无多余装饰。
- **动作**：标题逐字翻起（rise3d），卡片从景深里翻过来（flip3d），被旁白念到的卡片抬起并描边；转场轮换 zoomThrough / blurPush / whip。
- **配乐**：bouncy。
- **适合**：功能点多、需要「一屏展示很多卖点」的产品：效率工具、硬件参数、AI 助手的能力清单。
- **参考**：Apple 官网的 bento 卖点格、Notion / Arc 的功能页。

## 按产品类型速查

| 产品类型 | 首选 | 备选 |
| --- | --- | --- |
| 消费 App / 社区 | flat-mg | kinetic、bento |
| 视频 / 内容平台 | kinetic | flat-mg、editorial |
| SaaS / AI / B 端 | saas-glow | bento、apple-keynote |
| 硬件 | apple-keynote | bento |
| 游戏 / 电竞 | cyber-glitch | kinetic |
| 媒体 / 文化 / 生活方式 | editorial | apple-keynote |
| 独立开发 / 创意工具 | neo-brutal | flat-mg |

## 动作词汇表（runtime.js）

文字入场：`fadeUp` `blurIn` `letterSpace` `charStagger` `charPop` `maskUp` `punch` `typewriter` `glitch` `slideHard`

图片入场：`floatUp` `tilt3d` `zoomOut` `popBounce` `wipe` `glitch` `slideHard`

转场：`cut` `fade` `blur` `push` `pushUp` `zoom` `circle` `shapeWipe` `flash` `glitchCut` `stripes`

新风格可以自由组合这些预设，比如「editorial 皮肤 + charStagger + circle 转场」。
