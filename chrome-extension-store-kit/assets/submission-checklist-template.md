# Chrome Web Store 发布检查清单

## 插件包

- [ ] 已确认上传目录和构建产物
- [ ] `manifest.json` 可解析且版本正确
- [ ] Manifest V3
- [ ] 16/32/48/128 px 图标路径有效
- [ ] 未包含 `.git`、`node_modules`、缓存、测试数据或密钥
- [ ] 未下载或执行远程代码
- [ ] 权限与主机范围已最小化
- [ ] 已在 Chrome 中加载最终解压目录并测试核心流程
- [ ] 最终 ZIP 内容已人工检查

## 商店素材

- [ ] 128x128 商店图标

- [ ] 视觉素材未展示虚构功能或真实隐私数据
- [ ] 字体、图片和商标使用权已确认

- [ ] 审核人员测试说明已准备
- [ ] 发布地区、定价和成熟内容选项已确认

## 发布
