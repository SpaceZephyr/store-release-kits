# App Store submission checklist

## Build

- [ ] Correct bundle ID, version, build number, scheme, signing, and capabilities
- [ ] Current required Xcode/SDK verified
- [ ] Release archive validated and uploaded without unresolved warnings
- [ ] Tests pass on supported devices and OS versions
- [ ] No credentials, private API, placeholders, debug endpoints, or production personal data

## Product page

- [ ] Approved icon integrated into the target
- [ ] 3–5 accurate screenshots per required device/localization
- [ ] Screenshots pass exact sizes and have no alpha
- [ ] Name, subtitle, promotional text, description, keywords, and What's New are accurate
- [ ] Support, marketing, privacy, and privacy-choices URLs load publicly

## Privacy and legal

- [ ] App Privacy answers match app, SDKs, backend, and privacy policy
- [ ] `PrivacyInfo.xcprivacy` and required-reason declarations validate
- [ ] Permission strings are specific and localized
- [ ] ATT/tracking behavior is consistent
- [ ] Account deletion works when account creation exists
- [ ] Age rating, content rights, export compliance, regional qualifications, and agreements complete

## Review

- [ ] Correct build and related IAP/subscription items selected
- [ ] Review notes explain all significant/non-obvious behavior
- [ ] Demo account or demo mode gives full access
- [ ] Backend, sample content, hardware, and contact remain available
- [ ] Purchase, restore, permission denial, and deletion paths tested

## Release

- [ ] Pricing, territories, and release option confirmed
- [ ] TestFlight feedback reviewed
- [ ] Monitoring and phased-release/rollback plan ready
- [ ] Explicit authorization obtained before Submit for Review and release
