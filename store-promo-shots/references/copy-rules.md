# 宣传图上的文案怎么写

## 长度

- 主标题：一行不超过 8 个汉字（英文约 14 个字符），最多两行。
- 副标题：可以没有。有就一行，不超过 20 个汉字。
- 渲染器会按可用宽度自动缩字号。缩到明显偏小就说明这句话太长了，
  回去改文案，别靠缩字号硬塞。

## 写什么

写**用户能想象出画面的动作和结果**，不要写形容词。

| 别写 | 写 |
| --- | --- |
| 高效便捷的任务管理 | 一句话加任务，不用点五次 |
| 强大的提醒功能 | 到点提醒，不到点不打扰 |
| 丰富的数据统计 | 这周做完了多少，一眼看得见 |
| 极致的使用体验 | 打开就走，不用注册 |

## 排版技巧

**混字重。** 用 `**` 包住想跳出来的那几个字，其余部分会自动退到常规字重：

```
"headline": "到点提醒\n**不到点不打扰**"
```

参考图里 Unfold 那套「Aesthetic **Instagram** templates」就是这个写法，
一句话里有轻重，比全部加粗耐看。

**自己控制断句。** 用 `\n` 手动换行，别让它在奇怪的地方折。
断句要断在语义的停顿处：「一句话加任务 / 不用点五次」，
不要断成「一句话加 / 任务不用点五次」。

**标点。** 主标题末尾一般不加句号，除非是完整的一句话陈述
（「你好，我们是清单。」这种开场白可以加）。

## 徽章

拿过奖才能写。`badge` 支持 `editors-choice`、`new-apps-we-love`、`design-award`。
没拿过就别加，商店审核看得出来，而且用户也不傻。

## 品牌标

`wordmark` 会渲染在底部，一般只在第一张或最后一张放一次，
每张都放会很吵。
